# Legacy references

This directory contains historical AutoHotkey-era specifications, persistence notes, and interface
screenshots retained for migration fidelity and provenance. They do not describe how to install or
operate the current Python/PySide6 application.

- `AutoHotkey-Application-Specification.md` documents the earlier application behavior.
- `AutoHotkey-Persistence-Notes.md` documents the earlier text-file persistence design.
- `screenshots/` contains reference images used during the Python interface migration.

Current documentation starts at the repository [README](../../README.md).
